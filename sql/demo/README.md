# Demo data for the Vrelo agency (fictional)

`vrelo_history.json`: invented rental history (names, @example.com emails, DEMO licence numbers) so the owner
dashboard has something to show. Generated by `vrelo_history_gen.py`. Rows get a reference starting with `Z`.

Remove all demo rentals:

    delete from rc_bookings where ref like 'Z%' and business_id = (select id from businesses where slug = 'vrelo');
